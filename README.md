# دانلود منیجر 📥

یک دانلود منیجر سریع و کارآمد برای لینوکس و دبیان با رابط کاربری گرافیکی

## ویژگی‌ها ✨

- 📊 **رابط کاربری گرافیکی** - استفاده آسان و زیبا
- ⚡ **دانلود سریع** - پشتیبانی از دانلود‌های متوازی
- 📈 **نمایش پیشرفت** - میزان پیشرفت و سرعت دانلود
- 🎯 **کنترل کامل** - توقف و حذف دانلود‌ها
- 💾 **انتخاب مسیر** - ذخیره فایل‌ها در هر جای سیستم

## نیازمندی‌ها 📋

- Python 3.8+
- PyQt6
- requests

## نصب 🔧

### روش 1: استفاده از requirements.txt

```bash
git clone https://github.com/sadra-h68/download-manager.git
cd download-manager
pip install -r requirements.txt
python main.py
```

### روش 2: نصب دستی

```bash
pip install PyQt6 requests
python main.py
```

### برای دبیان/اوبونتو:

```bash
sudo apt update
sudo apt install python3-pip python3-dev
pip install PyQt6 requests
python3 main.py
```

## استفاده 🚀

1. لینک دانلود را در فیلد بالا وارد کنید
2. (اختیاری) مسیر دانلود را انتخاب کنید
3. دکمه "اضافه کردن دانلود" را بزنید
4. دانلود شروع خواهد شد
5. می‌توانید چندین دانلود را همزمان انجام دهید

## نکات ℹ️

- تعداد دانلود‌های همزمان را از پنجره تنظیمات کنترل کنید
- دانلود‌های متوقف شده خودکار حذف می‌شوند
- پیشفرض: فایل‌ها در پوشه Downloads ذخیره می‌شوند
